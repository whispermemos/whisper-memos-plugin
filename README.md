# Whisper Memos plugin

[Whisper Memos](https://whispermemos.com) turns the voice memos you record on your iPhone or
Apple Watch into text. This plugin lets your coding agent work with those memos.

## What it can do

- List your recent memos, filtered by label or date
- Read a memo's transcript and summaries
- Delete a memo you no longer need

It cannot record, create or edit memos.

## Example prompts

- "Summarize the memos I recorded this week."
- "Find my memo about the launch and list the action items."
- "Turn my latest memo into a GitHub issue."

## Setup

1. Install the plugin.
2. When asked to sign in, a Whisper Memos page opens in your browser.
3. Approve the connection in the Whisper Memos app on your iPhone.

You need an existing Whisper Memos account. The plugin only accesses memos in the account
you connect.

## How it works

The plugin holds no code. It points at the Whisper Memos MCP server,
`https://whispermemos.com/mcp`. You can also add that address by hand to any MCP client.
